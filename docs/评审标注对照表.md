# 评审标注对照表

界面上每个功能块的标题前有一个黄底黑字的字母圆标。同一页面（或页签）内从 A 开始编号。开会记录时写“页面名 + 字母”，例如“总览 C 改进：关键信息里加上每平尺单价”。

顶栏右侧“评审标注：开/关”可以隐藏或显示这些圆标，设置记在本机浏览器里。

## 工作台（首页）

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 今日概览 | 地址搜索框 + 四个指标（线索、在建、已投入、预计利润）；页面标题是今日关注一句话 |
| B | 需要关注 | 规则生成的洞察列表：超支、落后、缺文件、缺数据、待定价、未算账 |
| C | 在建项目：花了多少 | 每个在建项目一行子弹图：灰底 = 预算，彩条 = 实际，超出段红，右侧“实际 / 预算 · 百分比” |
| D | 阶段分布 | 一根三段堆叠条 + 图例列表（数量、占比） |
| E | 最近更新 | 三张带封面图的项目卡 |
| F | 项目列表 | 全部项目表格：缩略图、阶段、状态、预算已用、目标售价、更新时间；可筛选排序 |
| G | 未来 30 天 | 所有项目的买入、开工、计划完工、挂牌、成交日期，按时间排；逾期红、7 天内黄 |
| H | 资金占用 | 每个在建项目一根细堆叠条（买入价 + 已支出），条尾标合计；顶部一句总额 |
| I | 估算准不准 | 已完成项目表：售价偏差（高于目标绿）、预算偏差（超支红）、实际利润、工期 |
| J | 近 12 周支出 | 细线 + 面积晕染 + 末端数值，悬停十字线读数；顶部总额与周均 |
| K | 供应商支出前五 | 表；金额列带细条 |
| L | 线索漏斗 | 横向细条，一色渐深表示先后，条尾标计数 |

小组件可拖动、缩放、移除，字母跟着小组件走；移除后可从右上角“添加小组件”加回；布局记在本机浏览器。

## 项目列表页（侧栏“项目”）

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 项目列表 | 与工作台 F 相同的表格，独立成页 |

## 项目页：头部与工作流卡（所有页签共用）

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 身份卡 | 封面图、项目名、阶段与策略徽章、状态、地址与规格；“交易”一栏（买入 → 目标售价、预计利润与利润率）；“时间”一栏（关键日期串 + 工期进度）；编辑与操作按钮 |
| B | 工作流卡 1 | 线索：数据完整度；在建：预算已用；已完成：实际利润 |
| C | 工作流卡 2 | 线索：交易分析；在建：距计划完工；已完成：总工期 |
| D | 工作流卡 3 | 文件登记（三种阶段相同） |

## 总览 页签

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 数据完整度提示 | 只在有关键字段缺失时出现 |
| B | 生命周期 | 九段流程轨道（已完成实色、当前带圆点、未来浅色）+ 当前位置与下一步；四个里程碑列（线索 / 买入 / 施工 / 卖出）各写日期、金额、耗时 |
| C | 关键信息 | 买入价、目标售价、装修预算、预计利润、五个日期、面积、户型、交易分析版本数、挂牌价 |
| D | 预算：花在哪、哪超了 | 子弹图：灰底 = 预算，彩条 = 实际支出，超出预算的那段画红；顶部总条 + 按类别（前 6 类 + 其他），各行共用一把尺 |
| E | 状态 | 自动计算的状态与原因、规则说明 |
| F | 风险 | 可编辑的风险文本 |
| G | 备注 | 只在有备注时出现 |

## 分析 页签

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 头部与版本操作 | 保存状态、版本选择、版本菜单（新建轻/中/重装、设为当前、删除）、应用到项目 |
| B | 核心指标 | 八个指标块：总利润带盈亏色，其余带口径说明 |
| C | 买入成本 | 买入价 + 附加费用行（检验、评估、过户等） |
| D | 持有成本 | 月数、每月开销行、房贷开关与首付/利率/年限 |
| E | 装修明细 | 按类别的装修行，来源说明 |
| F | 卖出成本 | 卖出比例 + 其他费用行 |
| G | 售价 | 修好后能卖多少（来源标签） |
| H | 最高出价 | 目标利润率滑杆、最高可出价与 70% 法则两个数字、一根“当前买入价 vs 上限”的刻度条 |
| I | 成本结构 | 一根四段堆叠条（买入 / 持有 / 装修 / 卖出）+ 售价竖线；条比线短就有利润 |

## 数据 页签

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 房产、结构与地块 | 每个字段的值、主值来源、多来源冲突与选主值、人工修改 |
| B | 业主信息 | 业主、邮寄地址、持有自、电话、邮箱 |
| C | 当前按揭 | 贷方、类型、期限、余额、利率、月供 |
| D | 成交史 | 历次登记的买卖双方、契约类型、金额 |

## 文件 页签

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 上传并登记文件 | 选文件、类型、日期、对方、金额 |
| B | 文件登记表 | 全部文件：类型、阶段、日期、对方、金额、来源、大小、编辑/删除 |

## 预算 页签

| 字母 | 功能块 | 说明 |
|---|---|---|
| A | 汇总 | 四个指标块 + 一根子弹图（灰底 = 预算，红段 = 超出） |
| B | 预算 vs 实际 | 表；每行一根小子弹图（灰底 = 预算，红段 = 超出），差异列带方向色 |
| C | 预算项 | 计划金额明细，可增删 |
| D | 支出 | 逐笔支出，可增删 |
